sound destruction

This sample verifies that destroying a syngen.sound releases every audio node it owns: its output, its binaural processor, and, when enabled, its reverb send. It covers normal destruction, repeated destruction, and destruction while the fade is still running.

It tracks every connection in the audio graph because Web Audio does not expose them, then checks that no node is left wired into the mixer bus. It loads the library from the unbuilt sources, so no build step is required. Serve this directory over HTTP (for example with npx http-server) or open the file directly.
