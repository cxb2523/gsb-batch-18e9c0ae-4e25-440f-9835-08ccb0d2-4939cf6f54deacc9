# Design

Studio is a dark, quiet control panel around your own scene. The scene is the loudest thing on screen; the chrome gets out of the way. Implementation: `apps/studio/src/styles.css` (tokens are CSS variables at the top).

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | `#0b0c10` | App background, input wells |
| `--panel` | `#101117` | Panels, top bar |
| `--raised` | `#171923` | Buttons, selected segment, menus |
| `--hover` | `#1d2030` | Hover on raised surfaces |
| `--border` / `--border-strong` | `#22242f` / `#2f3242` | 1px dividers / control outlines |
| `--text` / `--muted` / `--faint` | `#e8e9ef` / `#9195a8` / `#5d6175` | Primary / secondary / disabled and hints |
| `--accent` | `#7c6cff` | **The only accent**: selection, primary button, slider fill, focus ring |
| `--ok` / `--warn` / `--danger` | `#3ecf8e` / `#e3b34b` / `#ff6b7a` | Status only (saved, partly editable, refused). Never decoration. |

Axis colors (x red, y green, z blue) appear only on the three vector inputs. Type: system sans for UI, system monospace for code, paths and numbers. Base 13px, small 12px, labels 11px uppercase with 0.06em tracking. Radius 5px controls, 8px groups. Spacing on a 4px grid. No web fonts, no icons font, no external requests.

## Layout

```
┌ top bar 48 ─ brand · template switcher · Hero.tsx state ·········· Reset · Copy .tsx ┐
│ Scene tree 264 │        viewport (sandboxed preview)         │ Inspector 320 │
│                │  toolbar: Edit|Preview  Scene cam|Free view │               │
│                │           Move|Rotate|Scale                 │               │
├ diff strip 156 ─ Changes · saved state · Undo · Redo · newest edit first ────────┤
```

Desktop only (1100px minimum). The viewport takes the remaining space.

## Components

- **Scene tree.** Source-ordered, indented by nesting. Nodes written inside wrapper components (`Spin`, `MouseFollow`) are listed under a separate **Behaviors** heading. Badges: none = fully editable, `partial` (amber) = some props are literals, `locked` = read-only, `map` = generated by `.map()`, `opaque` (dashed) = contents not understood.
- **Inspector.** Sections: Transform, Geometry, Material or Properties, Shader uniforms. Number fields scrub by dragging the label (Shift 10x, Alt 0.1x), arrow keys nudge. Rotation shows degrees and writes radians. A prop that is absent is shown dimmed with a "will add" hint and is inserted on first edit. A read-only prop shows its source text, a lock and the reason. Controls come from the value: number gets slider plus field, `#hex` gets a color well, boolean gets a switch, number arrays get one field per entry. `// @prism uniform` annotations in GLSL supply slider ranges and types.
- **Diff strip.** Each row is the exact one-line patch: file and line, summary, author chip, time, then the old line (red) and the new line (green) with the changed span highlighted. Newest first.
- **Viewport.** Edit (pick, gizmo, scene pointer handlers paused) or Preview (scene runs as visitors see it). Scene cam or Free view (orbit without touching the file). A "Paused while you edit" chip shows while a gizmo handle is hovered or dragged (d9).

## State matrix

| State | Viewport | Tree | Inspector | Diff strip |
|---|---|---|---|---|
| Booting | spinner, "Starting the sandbox…" | empty | "Nothing selected" | "none yet", status `idle` |
| Compiling | spinner over the last frame, "Compiling the scene…" | kept | kept | kept |
| Ready, no selection | scene | full | "Nothing selected" | as is |
| Ready, selected | scene, selection box, gizmo | row highlighted | sections for the node | as is |
| Locked node selected | selection box, no gizmo writes | `locked` / `map` / `opaque` badge | reasons list, locked rows | refusal message if an edit is tried |
| Edit refused | unchanged | unchanged | unchanged | red banner with the error code and message; status `refused` |
| Scene error (parse, runtime, shader compile) | error panel with the message | last good tree if parsing still works | kept | Undo and Reset stay available |
| Preview mode | scene live, "Preview" chip, no gizmo | kept | kept | kept |

## Copy and tone

Plain and literal. Say what happened ("Copied Hero.tsx (7.2 KB)"), not how it feels. Errors name the cause and the fix ("Undo your last edit, or reset the template"). The Playground says what it is: "saved in this browser", "template as shipped". Nothing implies the file lives anywhere else.
