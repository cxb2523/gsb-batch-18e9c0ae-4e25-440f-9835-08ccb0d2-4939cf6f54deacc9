# @prismbox/templates

Seven hero templates as single plain React Three Fiber `.tsx` files with no Prismbox import. Private package: not published. See [docs/writing-a-template.md](../../docs/writing-a-template.md).

`source/` holds the authoring files (GLSL blocks pulled in with `//@include`); `templates/` is the generated output that ships; `manifest.json` lists them.
